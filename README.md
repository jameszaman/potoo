# Potoo

A developer-first notification orchestration platform. One API for email — with templates, provider management, multi-tenant orgs, and a rich dashboard.

---

## What It Does

- **Multi-tenant platform** — a single platform org controls all customer organizations; new users join via invite links
- **Provider management** — bring your own email provider (Resend, SendGrid, or SMTP); connections stored per org
- **Template editor** — block-based rich text editor with bold, italic, underline, strikethrough, links, images, buttons, headings, lists, dividers, and alignment; templates are versioned and activated explicitly
- **API keys** — create and revoke API keys per org; keys authenticate all programmatic API calls
- **Session auth** — JWT-based sessions with HttpOnly cookies, 15-minute access tokens, 30-day rotating refresh tokens, and silent refresh on expiry
- **Delivery pipeline** — delivery records and event timelines; inbound provider webhooks update status in real time
- **Background worker** — Asynq + Redis queue for async email dispatch

## Running Locally

### Prerequisites

- Go 1.22+
- Node.js 20+ and pnpm
- Docker Desktop (for Postgres + Redis)
- [golangci-lint](https://golangci-lint.run/welcome/install/)
- [oapi-codegen](https://github.com/oapi-codegen/oapi-codegen): `go install github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@latest`
- [sqlc](https://docs.sqlc.dev/en/latest/overview/install.html): `go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest`
- pre-commit: `pip install pre-commit`

### First-time setup

```bash
git clone <repo-url>
cd NotifyLayer
make setup       # install deps and git hooks
make db-up       # start Postgres + Redis
make migrate     # run all migrations
```

### Environment variables

Copy `.env` and fill in values:

```
DATABASE_URL=postgres://postgres:postgres@localhost:5432/potoo?sslmode=disable
REDIS_ADDR=localhost:6379
ALLOWED_ORIGIN=http://localhost:3000
JWT_SECRET=change-before-deploy
API_BASE_URL=http://localhost:8080
STORAGE_DRIVER=local
STORAGE_LOCAL_PATH=./uploads
```

### Running the services

```bash
make api         # API server on :8080
make worker      # background worker
make web         # Next.js dashboard on :3000
```

Or run everything at once:

```bash
make dev         # start DB, migrate, generate
```

### First run

Navigate to `http://localhost:3000` — you will be redirected to `/setup` automatically. Fill in the platform org details and owner account (name, email, password) to complete initial setup.

`/setup` is only accessible once. After setup it is permanently locked and the API returns `410 Gone` on repeat calls.

New users join via invite links generated by the platform owner from the dashboard (`/dashboard/invites`).

## Auth

### Dashboard (session-based)

The dashboard authenticates with JWT access tokens stored in an HttpOnly cookie (`pt_access`, 15-minute TTL). A rotating refresh token (`pt_refresh`, 30-day TTL) is used to silently renew the access token — no action needed from the user.

### Programmatic API (API key)

All non-auth API endpoints accept a Bearer token:

```
Authorization: Bearer <api_key>
```

API keys are created and revoked from the dashboard under **API Keys**. Each key is scoped to an organization and resolves the tenant context (org → default project → production environment) on every request.

## Email Providers

Supported providers:

| Provider | Type | Notes |
|---|---|---|
| Resend | API | Webhook delivery receipts supported |
| SendGrid | API | Webhook delivery receipts supported |
| SMTP | SMTP | Port 465 = implicit TLS, port 587 = STARTTLS; no delivery receipts |

Provider connections are created per org from the dashboard under **Providers**. Credentials are stored encrypted. SMTP requires host, port, username, and password; `from_email` and `from_name` are optional.

---

## Templates

Templates are created and edited from the dashboard under **Templates**. Each template has a unique key (e.g. `welcome_email`) used to reference it at send time.

The editor supports:
- Block types: paragraph, headings (H1–H6), bullet list, numbered list, blockquote, divider, image, button
- Inline marks: bold, italic, underline, strikethrough, links
- Alignment: left, center, right
- Variable interpolation: `{{variable_name}}`

Templates are versioned. Each save creates a new version which is immediately activated. The active version is what gets rendered at send time.

```
  providers/email/          Email provider interface + Resend, SendGrid, SMTP adapters

```
